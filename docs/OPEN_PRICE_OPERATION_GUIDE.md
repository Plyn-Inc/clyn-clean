# CLYN OPEN PRICE 운영 가이드 (2026-09-16)

## 결론: 코드 수정 없이 Admin 설정만으로 가격이 결정된다

`/one-room`과 메인 Hero의 `CLYN OPEN PRICE`는 **금액이 코드에 없다.**
`price_rules`(원룸 기본가) + `discount_promotions`(자동 프로모션) 조합을 서버가 계산해 내려준다.

```
src/lib/offers.ts  getOneRoomOffer()
  getServiceProductPrice("입주청소", "원룸")   → basePrice
  calculateDiscounts(...)                      → openPrice / discountAmount / promotionName
```

표시가격과 실제 예약 견적이 **같은 함수(`calculateDiscounts`)** 를 쓰므로 구조적으로 어긋날 수 없다.

## 139,000원으로 운영하려면

Admin → **할인 관리 → 자동 프로모션**에서 아래대로 등록한다.

| 항목 | 값 |
|---|---|
| 이름 | 오픈 프로모션 (자유) |
| 할인 방식 | 정액 (원) |
| 할인값 | **40000** |
| 적용 서비스 | 비움 (전체) 또는 `입주청소` |
| 적용 상품 | 비움 (전체) 또는 `원룸` |
| 시작/종료 | 필요 시 지정 (KST) |
| 활성 | 체크 |

```
179,000 − 40,000 = 139,000
```

**검증 결과 (로컬 PostgreSQL, production build)**
```
GET /api/offers/one-room
  { basePrice: 179000, openPrice: 139000, discountAmount: 40000, promotionName: "..." }
POST /api/quote (입주청소 · 원룸)
  finalAmount = 139000          ← 동일
```

## 프로모션을 끄면

```
{ basePrice: 179000, openPrice: 179000, discountAmount: 0, promotionName: null }
```
정상가 179,000원이 자동 노출된다. **코드 수정이 필요 없다.**

## 동작 확인 표 (실제 실행)

| 설정 | 표시가 | 실제 견적 | 일치 |
|---|---|---|---|
| 정액 40,000 | 139,000 | 139,000 | O |
| 정액 20,000 | 159,000 | 159,000 | O |
| 정률 20% | 143,200 | 143,200 | O |
| 프로모션 없음 | 179,000 | 179,000 | O |
| 비활성 / 기간 밖 | 179,000 | 179,000 | O |
| 여러 개(5,000 / 15,000 / 40,000) | 139,000 | 139,000 | O (가장 큰 1개만) |
| 기본가 199,000 + 40,000 할인 | 159,000 | 159,000 | O |

## 예외 처리

**원룸 상품이 비활성이거나 가격이 없을 때**
`/api/offers/one-room` → `404 { error: "현재 원룸 온라인 가격을 확인할 수 없습니다." }`
화면은 **"예약에서 최종 가격 확인"** 으로 대체된다. 임의 금액이나 0원을 표시하지 않는다.

## 주의

- 프로모션은 **최대 1개만** 적용된다. 여러 개가 조건을 만족하면 고객에게 가장 유리한 것 하나만 적용되며 중첩되지 않는다.
- 쿠폰은 별개다. 자동 프로모션 적용 후 금액을 기준으로 추가 적용된다.
- 프로모션을 수정·중지해도 **이미 접수된 예약의 금액은 변하지 않는다** (예약 snapshot 보존).
- 기본가 자체를 바꾸려면 Admin → 가격 관리 → 입주청소 → 원룸에서 수정한다.
